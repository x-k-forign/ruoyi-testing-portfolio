### 场景练习

以下为练习假设：
小王和小李都属于销售部。
小王可以查询用户，小李可以查询和新增用户。

1. 这个场景中，“用户”和“部门”分别是什么？：用户是小王和小李，部门是销售部
2. 两人属于同一部门，是否就一定拥有相同操作权限？为什么？：不一定。部门表示组织归属，不能仅凭部门相同判断操作权限相同。因为小王只可以查询，小李可以查询和新增用户
3. “可以查询用户”是否就意味着“可以查看所有部门的用户”？为什么？（AI 修订说明，非用户独立作答）：不意味着。查询操作权限与数据范围需要分别判断；应核对角色的数据范围和具体查询，不能仅凭销售部归属推断只能看销售部，也不能认定只有 Root 才能看其他部门。依据见正式需求分析 S03、S12—S14。

```

|---|---|
| 用户 | 系统怎样识别使用它的人？ |

| 菜单权限 | 用户能看到哪些功能入口？ |
| 操作权限 | 用户能执行哪些动作，例如查询、新增、删除？ |
| 数据权限 | 用户获准查询后，能看到哪些记录？ |
| 登录日志 | 怎样追查登录成功或失败的情况？ |
| 操作日志 | 怎样追查用户执行过的相关操作？ |
```
