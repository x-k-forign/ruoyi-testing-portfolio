# 同部门查询角色与维护角色的新增权限对照

原 TC 为 `TC-A02-01`。覆盖菜单、按钮及获准操作的页面部分，依据 E04/E05，对应风险 RK04/RK09。

- 前置。甲、乙为同部门的新测试账号，均获准查询，乙另外有新增权限。核对实际配置，准备乙可分配的部门和角色。
- 操作。甲、乙使用独立浏览器会话登录。双方在同等条件下打开用户管理并查询，待列表及权限渲染就绪，观察新增入口。乙通过该入口提交本例专用用户，并重新搜索。
- 预期。双方可进菜单并查询。按 T3 权限矩阵，甲不显示新增按钮。若按钮存在但禁用，按实际页面状态记录差异。乙的按钮可用，新增记录能按标记回查。甲的页面表现只支持页面结论。
- 收尾。清理本例创建的用户和辅助数据，回查确认已移除。
